## Reviewed public derivations

The native coordinate is `p=q*me/x` (Nudec `System_Nudecoupling.py:114`). With `x=a*me`, `q` is the numerical native code coordinate; the upstream grid docstring's MeV label is not adopted here. Physical `p` and the masses are in MeV. When the muon term dominates, the selected maximum is `qmax=x_stop*mmu/2` (`Core.py:74`). Together these give an active-source limiting physical maximum of `me*mmu/2` as `x -> x_stop^-`. The exact cutoff row has source off because the gate is `x<stopPoint` (`System_Nudecoupling.py:116`). Local clipping fractions must not be reported as integrated whole-history losses.

The native field counts primary muons per parent decay, so the frozen pair probability maps to `N_mu=2*B_mumu`. The explicit factor one half in the native occupation source (`System_Nudecoupling.py:119–120`) then gives each neutrino and antineutrino species its prescribed `B_mumu` coefficient. Adding another factor one half would be wrong. The three native occupations impose neutrino/antineutrino equality; they are not six independently evolved states.

For a declared reference density `s_ref=s0*(x0/x)^3`, the source conversion is `dY/(dt dq)=c*p^2*(df/dt)/(2*pi^2*s_ref)`, where `c=dp/dq=me/x`. This reproduces `B_mumu*Y0*exp(-t/tau)/tau*c*K(p)`. Choosing a thermally evolving plasma entropy density instead requires a different, explicit convention. The audited source algebra and density reference values are correct.

The system RHS applies averaged mixing after accumulating the source and then adds collisions. A post-mixing tau component is compatible with a pre-mixing zero-tau source. A full system-RHS difference cannot be relabeled as the six canonical pre-collision, pre-oscillation arrays without a documented adapter and source-stage export.

The native cutoff is an interpolated reference-table `x_stop`, not the evolved state's time. It does not establish the half-open frozen gate `0<=t<18*tau`. Parent exponential density remains in Hubble after injection/deposition stop. At an actual `18*tau` cutoff the parent fraction is `exp(-18)`, but this is not a bound on an abundance or proof of the actual cutoff time.

The proxy omits the lower grid cutoff and does not redshift the injected energies to a later epoch. Reference clipping starts at `t/tau=4.773549664`. They illustrate why large local limiting deficits do not imply correspondingly large whole-history losses.

`table_proxy_sensitivity.py` independently checks the proxy. That is interpolation sensitivity, not a physical uncertainty estimate for an unknown production history.

The rounded native muon mass differs by `3.939536246e-4` from the frozen source. Full-domain moments through fifth order differ by at most `1.971320729e-3`, below the loose `5e-3` moment gate. The muon cumulative-distribution discrepancy is `7.875968504e-4`; native muon-flavor number above the frozen endpoint has the same fraction. These are continuum calculations, not claims about which forbidden-tail nodes a particular finite returned grid samples or a completed bridge validation.

## PRIMAT kinematic interpretation

At current commit `4bf97d5082eee54b9df50d88f43182bb651fea80`, Python `primat/weak_rates/corrections.py:537–539` and the C weak-rate implementation use dimensionless electron momentum `pmax=max(7,30/x)`, with `x=me/(kB*T_gamma)`; the Python callable's `T_arr` is in Kelvin. Physical electron momentum is therefore `Pmax=max(7*me,30*physical_T_gamma_MeV)`, and electron energy is `Ee_max=sqrt(Pmax^2+me^2)`.

The positive electron-energy branch gives incoming `nu_e+n->p+e-` maximum `Ee_max-Delta`; the positive branch for the opposite direction gives incoming `anti_nu_e+p->n+e+` maximum `Ee_max+Delta`. The source's distortion callable already receives signed, shifted neutrino energy; subtracting the nucleon splitting a second time would be wrong. The signed negative branch also probes final-state blocking and does not extend incoming electron-neutrino capture support.

At physical photon temperature `0.1 MeV`, Python/C incoming ceilings are `2.3199758672` and `4.9066405872 MeV`. Full frozen endpoint inclusion requires at least `1.8040035917` and `1.7177773982 MeV`, respectively, under static Born kinematics. Bundled Mathematica `generate_rates/PRIMAT-Main.m:1404–1405` instead uses floor 12; any broader claim must identify the executed implementation. Its low-temperature limits differ, while the high-energy crossover temperatures above are unchanged.

The thermal exponential-tail argument does not establish adequacy for an injected high-energy spectrum. Spectral-distortion functions use the same truncated grid (`corrections.py:714,746`) while the incoming high-energy branch has final electron blocking `FD2(-E,x) -> 1` (`:721–724`). Default NEVO lookup has a separate out-of-range-zero policy. Increasing nodes on a fixed domain cannot reveal omitted support. These are instantaneous coordinate bounds; actual rate coverage must consider the evolved/redshifted spectra, ongoing injection, both species, interpolation range and enabled corrections.
